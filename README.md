# 🩺 MediFind AI

An AI-powered Doctor Discovery System built using Spring Boot.

## 🚀 Features

- Doctor Registration
- Patient Registration
- JWT Authentication
- Doctor Discovery
- Search & Filtering
- Pagination
- PostgreSQL Database
- AI Symptom Analysis (LLM)
- Swagger API Documentation

---

## 🛠 Tech Stack

### Backend
- Java 21
- Spring Boot 3
- Spring Security
- Spring Data JPA
- Hibernate

### Database
- PostgreSQL

### AI
- Spring AI
- OpenAI / Gemini

### Build Tool
- Maven
